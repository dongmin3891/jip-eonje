# 집언제

서울 SH 행복주택 예비입주자가 단지를 검색하거나 지도에서 고르고, 공개된 전월세 계약과 공가 안내를 한 화면에서 보게 하는 웹앱입니다. 매매가, 시세 예측, 투자 분석, 중개, 로그인, 데이터베이스는 다루지 않습니다.

지도에 올리는 단지는 서울 열린데이터광장 주택관리현황에서 주택유형에 「행복」이 있는 행만입니다. 공가·예비자 수는 조회하지 않고, 단지별 SH 공식 주택정보 페이지로 보냅니다. 상세 주소를 확인하지 못한 단지는 주택정보 메인으로 보냅니다. 전월세 건수는 당첨이나 입주 인원이 아닙니다.

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

개발 서버는 4317 포트입니다. 키가 없어도 단지 검색과 목록은 동작합니다. 지도 키와 실거래 키가 없으면 각각 미설정 안내를 보여주고 앱은 멈추지 않습니다.

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm start
```

단지 목록을 공식 원본에서 다시 만들려면 `npm run data:complexes` 를 실행합니다. 좌표가 없는 단지를 카카오 주소검색으로 채우려면 `KAKAO_REST_API_KEY` 가 있어야 합니다. 키가 없으면 좌표를 추정하지 않습니다.

## 환경변수

| 이름 | 어디서 | 용도 |
| --- | --- | --- |
| `DATA_GO_KR_SERVICE_KEY` | 서버 | 국토부 아파트 전월세 실거래 |
| `KAKAO_MAP_JS_KEY` | 서버에서 읽어 지도 SDK에 전달 | 카카오맵. `NEXT_PUBLIC_` 로 두지 않는다 |
| `KAKAO_REST_API_KEY` | 목록 생성 스크립트 | 선택. 좌표 보완용 지오코딩 |

값은 `.env.local` 에만 둡니다.

### 공공데이터포털 키

1. [아파트 전월세 실거래가 자료](https://www.data.go.kr/data/15126474/openapi.do) 에서 활용신청을 합니다.
2. 일반 인증키(인코딩 또는 디코딩)를 `DATA_GO_KR_SERVICE_KEY` 에 넣습니다.
3. 개발계정은 트래픽 제한이 있습니다. 최근 두 달은 6시간, 그 이전 달은 7일 동안 서버 메모리에 캐시합니다. 같은 클라이언트는 1분에 20번까지 조회할 수 있습니다.

### 카카오맵 키

1. [카카오 개발자](https://developers.kakao.com/) 에서 앱을 만들고 JavaScript 키를 발급합니다.
2. 플랫폼에 웹 도메인을 등록합니다. 로컬은 `http://localhost:4317` 입니다.
3. 키를 `KAKAO_MAP_JS_KEY` 에 넣습니다. 지도 SDK가 브라우저에서 이 키를 쓰므로, 콘솔의 도메인 제한으로 보호합니다.

REST API 키는 지도와 별개입니다. 좌표가 비어 있는 단지를 채울 때만 `KAKAO_REST_API_KEY` 로 `npm run data:complexes` 를 실행합니다.

## 연동하지 않는 것

SH 단지별 공가, 공급형별 예비자, 최근 1년 퇴거는 내부 API로 조회하지 않습니다. 자치구, 단지명, 도로명 주소가 맞는 단지만 [공식 상세페이지](https://www.i-sh.co.kr/houseinfo/main/selectHouseImgInfo.do?ctgrCd=10&biznsCd=70536)로 연결하고, 나머지는 [SH 주택정보](https://www.i-sh.co.kr/houseinfo/main/selectFromMain.do) 메인으로 보냅니다.

마이홈 예비입주자 대기 API는 공가 수가 없고, SH 단지가 포함되는지는 인증키 없이 확인하지 않았습니다. 그래서 이 앱의 공가 자리에 넣지 않습니다.

## 확인한 것, 확인하지 못한 것

확인한 것:

- OA-12027, OA-15818 원본을 받아 위 단지 수와 좌표 수를 다시 만들었습니다.
- 금액·기간·주소 매칭·XML 파싱·검색·미지원 문구는 단위 테스트로 확인했습니다.
- 키가 없을 때 지도와 실거래가 각각 미설정으로 보이는지 화면에서 확인했습니다.

확인하지 못한 것:

- 유효한 공공데이터포털 키로 실거래 API를 호출하지 않았습니다. 이 환경에 키가 없습니다.
- 유효한 카카오 JavaScript 키와 등록된 도메인으로 지도가 그려지는지 확인하지 않았습니다.
- 카카오 지오코딩으로 좌표 66곳을 채우지 않았습니다.
